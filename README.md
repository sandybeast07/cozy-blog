# CozyBlog

**Live Demo:** https://cozyblog.vercel.app  

CozyBlog is a modern, minimal, and cozy-themed blogging platform built to provide a smooth and distraction-free reading experience. The project focuses on clean design, performance optimization, and responsive layouts.

---

## Tech Stack

- **Framework:** Next.js  
- **Styling:** Tailwind CSS  
- **Language:** JavaScript  
- **Deployment:** Vercel  

---

## Features

- Blog post listing page  
-  Dynamic individual blog post pages  
-  Clean and cozy user interface  
-  Fast performance and optimized loading  
-  Fully responsive design  
-  Modern typography and layout
